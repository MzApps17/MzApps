# MzApps - Blueprint (Theihnghilh loh nan)

## Login Flow: Phone OTP Only
Phone Number -> OTP -> Name + Profile Pic -> HOME
No signup, No forgot password

## Footer (Icon 5) - Page tin ah lang:
Home | Chat | Status | Online | Profile

## Pages:
1. Home: Header Search (sticky, tawlh lo), Friends post (pic+thu)
2. Chat: Header Search highlight + Chat+ icon -> User list, Chat list (typing, tick, last seen)
3. Status: Search highlight, WhatsApp ang status update
4. Online: Search highlight, Online friends list
5. Profile: Instagram ang - Post zat, Friend zat, About, All posts. Pic click = profile view

## Rule: Profile pic + hming click apiangin profile en theih.

## Tech: Next.js + Firebase Phone Auth + Firestore
